These five original, user-supplied PNGs are stored in `public/brand/prof-nota/`. Each is listed in [`asset-manifest.json`](./asset-manifest.json) with its SHA-256 digest and original size. Their Git blob hashes were also compared with the local originals on 2026-10-25. Run `npm test` to check binary integrity and UI asset references.
